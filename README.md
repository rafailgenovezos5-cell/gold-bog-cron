# gold-bog-cron

Χρονοπρογραμματιστής για το [xrysi-lira-live](https://xrysi-lira-live.vercel.app).

Το μόνο που κάνει αυτό το repo είναι να καλεί το `/api/cron-check` του site κάθε
5 λεπτά, ώστε οι τιμές χρυσής λίρας να ελέγχονται αυτόματα — χωρίς να χρειάζεται
να είναι ανοιχτός κάποιος υπολογιστής ή το ίδιο το site.

## Γιατί ωριαίο schedule και όχι `*/5`

Το GitHub καθυστερεί ή παραλείπει τα scheduled workflows σε περιόδους φόρτου,
και τα πολύ σύντομα intervals (`*/5`) είναι τα πρώτα που «πέφτουν» — στην πράξη
έτρεχε περίπου κάθε 2,5 ώρες αντί για κάθε 5 λεπτά.

Γι' αυτό το workflow ενεργοποιείται **ωριαία** (το GitHub τηρεί πολύ πιο
αξιόπιστα τα ωριαία προγράμματα) και μέσα στο job κάνει **12 κλήσεις ανά 5
λεπτά**. Έτσι η συχνότητα των 5 λεπτών διατηρείται ακόμη κι όταν η ίδια η
ενεργοποίηση αργήσει.

Το repo είναι δημόσιο επειδή τα public repositories έχουν απεριόριστα δωρεάν
λεπτά GitHub Actions· σε private repo το όριο των 2.000 λεπτών/μήνα δεν επαρκεί
για συνεχή έλεγχο ανά 5 λεπτά.

## Ρύθμιση

Χρειάζεται ένα repository secret:

| Secret | Περιγραφή |
| --- | --- |
| `CRON_TOKEN` | Πρέπει να ταιριάζει με τη μεταβλητή `CRON_SECRET` του Vercel project |

**Δεν υπάρχει κανένα μυστικό μέσα στον κώδικα** — το token διαβάζεται
αποκλειστικά από το secret.

## Δεδομένα

Το ίδιο το repo δεν αποθηκεύει τίποτα. Το `/api/cron-check` συγκρίνει τις
τρέχουσες τιμές με την τελευταία αποθηκευμένη εγγραφή στο Supabase και γράφει
νέα γραμμή **μόνο όταν αλλάξει πραγματικά** η τιμή· διαφορετικά ενημερώνει μόνο
το `checked_at`.
